# Site de casamento — MVP de referência

Protótipo estático (arquivo único `index.html`) usado como referência visual e de conteúdo antes da montagem final na iCasei (plano Black).

- Todos os textos, datas, locais, hospedagem, presentes e FAQ ficam no objeto `CONFIG` no início do `<script>`.
- Fotos atuais são placeholders (picsum.photos). Para usar fotos reais, coloque em `fotos/` e aponte os caminhos no `CONFIG`.
- Pagamentos e RSVP são **simulados**: nada é cobrado nem enviado (RSVP fica só no navegador).
- Publicado via GitHub Pages com `noindex` para não aparecer em buscadores.
